Scheduled tasks

They run inside the chosen session while the app is open, even with the browser closed. Commands are always denied in scheduled runs; connectors only if you allow them below. Requires keys saved on this PC (Settings).

Connectors (MCP)

Any MCP stdio server works. Two zero-dependency ones ship with Galatea: Gmail (send email via app password) and WhatsApp (Meta Cloud API). Edit the JSON, save, and their tools appear to the model. Every connector call still asks for your approval.
